# Sort & Unique Lines

One keystroke, sorted and deduplicated. Select lines (or nothing for the whole file), press **F9**, done.

## Features

- Sorts lines ascending (or descending, configurable)
- Removes duplicate lines
- Trims whitespace (configurable)
- Strips blank lines (configurable)
- Case-insensitive by default
- Works on selection or entire file
- Undo with `Ctrl+Z` as usual

## Defaults

| Setting             | Default     |
| ------------------- | ----------- |
| Sort order          | ascending   |
| Case sensitive      | off         |
| Remove blank lines  | on          |
| Trim whitespace     | on          |

All configurable via **File > Preferences > Settings** → search "Sort & Unique Lines".

## Keybinding

Default: **`F9`**. Change it in Keyboard Shortcuts → search "Sort & Unique Lines".

## Stack

Bun + TypeScript + Biome. Zero runtime dependencies.
